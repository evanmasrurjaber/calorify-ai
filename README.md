## Overview

Bangladesh is seeing a rise in diet related health issues, while personalized nutrition guidance remains expensive and largely inaccessible. Mainstream calorie tracking apps offer little support for traditional Bangladeshi cuisine, and manual food logging has poor retention.

Calorify fills this gap. It uses the Gemini API to generate medically informed, culturally relevant diet plans, estimates calories directly from meal photos, and connects with Google Health to pull wearable data all tailored for the Bangladeshi context. A Bkash integrated subscription model and local grocery links (Chaldal, Shopno) make it practically useful from day one.

## Features

### Core

| Feature | Description |
|---|---|
| **Auth & Profiles** | JWT-secured registration and login. Users maintain a health profile with weight, height, goals, allergies, and medical conditions. |
| **Personalized Diet Plans** | 7-day meal plans generated by Gemini using the Mifflin-St Jeor TDEE formula, health profile, uploaded lab reports, and wearable data. Individual meals or full days can be regenerated without resetting the rest of the plan. |
| **AI Calorie Estimator** | Upload a photo of any meal. A FastAPI microservice detects food items, estimates portions, and returns calorie and macronutrient breakdowns. |
| **AI Meal Logging** | Log meals by text description. Gemini estimates calories and micronutrients and persists the data automatically. |
| **Daily Intake Tracker** | Visual progress bar for calories, carbs, protein, and fat against the user's daily target. Weekly summaries feed into the monthly health report. |
| **Smart Medical Report Parser** | Upload a PDF or image of a lab report. Gemini extracts diagnoses, HbA1c, blood markers, and allergies in structured JSON. This data is fed directly into diet plan generation. |
| **Shopping List Generator** | Automatically derives a weekly grocery list from the active diet plan. Items are grouped by category, cached in MongoDB, and can be ticked off as you shop. |
| **Online Marketplace Integration** | Each shopping list ingredient links directly to Chaldal or Shopno (user's choice) via a platform-specific search URL. |
| **Progress Tracker** | Daily weight logs and plan adherence streaks visualized as a line chart. Data feeds into the monthly health report. |
| **Gamified Challenges** | Daily micro-challenges (e.g., "Drink 2L Water", "Walk 5000 Steps") that award points and unlock tier badges: Healthy Starter → Nutrition Master → Diet Legend. |
| **Monthly Health Report** | Downloadable PDF compiled at month-end, covering calorie trends, nutrient averages, weight trajectory, adherence %, and personalized suggestions. |
| **Email Notifications** | Meal reminders, weekly plan refreshes, and account events delivered via Gmail API. Notification preferences are manageable from the user's profile. |
| **AI Recipe & Ingredient Trivia** | Clicking "Generate Recipe" on any meal returns full cooking instructions alongside 2–3 localized nutritional or historical facts about the dish's core ingredients. |
| **Wearable Sync (Google Health)** | OAuth2 consent flow to connect a Google account. Daily step count and active calories burned are synced and surfaced in the diet plan and progress tracker. |
| **Pro Subscription** | Premium tier with unlimited AI food scans, processed through the Bkash Payment API. Subscription status is stored in MongoDB and unlocks restricted features on payment. |
| **Admin Dashboard** | Platform-wide analytics: user growth over 7/30/90-day windows, DAU/MAU, total diet plans generated, calorie scans, community posts, and notification delivery rate. |
| **Community** | Users can create and interact with community posts. Admins can monitor post growth. |

## Tech Stack

**Frontend**
- React 19 + Vite
- React Router v7
- Tailwind CSS v4
- Recharts
- Axios

**Backend**
- Node.js + Express 5
- MongoDB + Mongoose

- Frontend: Vercel
- Backend: Render / Railway
- ML Service: HuggingFace Spaces

## Getting Started

### Prerequisites

- Node.js >= 18
- MongoDB (local or Atlas)
- A Google Cloud project with Gemini API and Gmail API enabled
- A Google OAuth2 client configured for Google Health access
- Bkash merchant credentials (for payment features)

### Installation

```bash
# Clone the repository
git clone https://github.com/evanmasrurjaber/calorify-ai.git
cd calorify-ai

# Install server dependencies
cd server
npm install

# Install client dependencies
cd ../client
npm install
```

### Environment Variables

Create a `.env` file inside both `server/` and `client/` based on the examples below.

**`server/.env`**
```env
PORT=5000
MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

GEMINI_API_KEY=your_gemini_api_key

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_REDIRECT_URI=http://localhost:5000/api/wearable/callback

GMAIL_USER=your_gmail_address
GMAIL_CLIENT_ID=your_gmail_oauth_client_id
GMAIL_CLIENT_SECRET=your_gmail_oauth_client_secret
GMAIL_REFRESH_TOKEN=your_gmail_refresh_token

BKASH_APP_KEY=your_bkash_app_key
BKASH_APP_SECRET=your_bkash_app_secret
BKASH_USERNAME=your_bkash_username
BKASH_PASSWORD=your_bkash_password

CALORIE_API_URL=your_fastapi_microservice_url
```

**`client/.env`**
```env
VITE_API_URL=http://localhost:5000
```

### Running the App

```bash
# Start the backend (from /server)
npm run dev

# Start the frontend (from /client)
npm run dev
```

The frontend runs at `http://localhost:5173` and the backend at `http://localhost:5000`.
